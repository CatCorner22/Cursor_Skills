# Skill run 3: blind test on 24 new contracts, November 6, 2026

Round 1 (c01-c26) had shaped the skill's fixes, so it was no longer a blind test. Round 2 added 24 new contracts (c27-c50), written by 3 helpers who saw neither the skill's code nor round 1, and aimed at what round 1 didn't cover. I audited every key before any review ran and corrected 1 wrong trap (*Third-Party Claim*, which MSCD 13.875 names as a term to avoid) and 2 missing issues (*third-party media costs*).

Then 6 fresh helpers used the skill exactly as it stood, with no round-2 fixes: 5 did reviews (22 contracts), and 1 did redlines with tracked changes and comments (c30 and c33).

## Accuracy

| Tier | Contracts | Found / planted |
|---|---|---|
| obvious | 6 | 104 / 104 |
| mixed | 8 | 87 / 87 |
| sneaky | 10 | 49 / 49 |
| **Total** | **24** | **240 / 240** |

Before 2 scorer fixes, the scorer missed 4 of the 209 problems in the 22 reviews. I read all 4, and each was a real finding that the scorer couldn't match:

- 2 used a fix of the form *keep only if intended; otherwise ...*.
- 2 flagged a conflict at its other end.

The scorer now treats a keep-or-change fix as a change and accepts an `alt_anchors` list for a conflict's other end. It now also credits a document-wide numbering finding at any heading.

**Traps.** The scorer flagged 9 of 106. Read one by one, every one is a correct finding about a different problem in the same words, except 1 borderline case:

| Contract | Trap | What the finding said |
|---|---|---|
| c34 | *Client shall terminate the campaign if* | Borderline: it asked whether a duty, discretion or an automatic end was meant, though *shall* is right for a duty |
| c27 | *is not required to perform* | *work* in lowercase next to the defined *Work* (MSCD 6.11) |
| c31 | *a party must give the other party* | the minimum-notice count and when a withdrawal takes effect |
| c35 | the introductory clause | justified text |
| c37 | *Tuesday, February 29, 2028* | the weekday repeats the date (MSCD 1.56); the date itself was accepted |
| c39 | the section line | *hereby* missing (MSCD 3.50, severity 3) |
| c42 | the introductory clause | no lead-in |
| c50 | the section line | typed numbering |
| c50 | *Manager shall terminate the engagement if* | no deadline to terminate |

**Redlines.** Both passed the docx skill's validator against the originals. Every tracked change is by Blake's AI Agent, with a comment giving its reason:

- **c30:** 24 insertions, 25 deletions and 37 comments.
- **c33:** 20 insertions, 22 deletions and 50 comments. Dana Whitlock's 3 existing comments were kept.

**Real problems the keys didn't plant.** The reviews also found problems that no key listed. 2 I checked against the text:

- **c45:** the escrow terminates whenever the license agreement does, even if it ends because of the depositor's breach. The materials then go back to the depositor, which defeats the escrow.
- **c47:** the rent formula calls for an MAI appraiser, but the fallback 3rd appraiser's determination binds the parties with no MAI requirement.

## Cost

6 helpers, 1,981,428 tokens, about 82,600 tokens and 5.0 minutes per contract (the 2 redlines took longer than the reviews).

## What the run showed, and what changed

The lint, scored blind on round 2, found 177 of 240 (110 of 125 lint-detectable) and flagged 2 traps. After the fixes below it finds 211 of 240 (125 of 125) with no trap flagged, and round 1 went from 245 to 255 of 303 with the same single, correct adjacent flag.

| Problem | Change |
|---|---|
| The lint didn't read page headers and footers, so it missed numeric dates in 3 of them | It reads them (after the body, so paragraph numbers don't move) |
| It couldn't see Word's automatic numbering | It reads each number from the list definitions and checks the outline, only children and headings |
| Words and digits that disagree (*Four Hundred Eighty-Two Thousand ... ($428,500)*) got only the words-and-digits style finding | A new severity-1 check compares the 2 values (fractions in words are skipped) |
| No check for impossible dates or wrong weekdays | New severity-1 check |
| *Consultant's employees shall*, *Site staff shall* | New check: a duty on a nonparty binds no one (MSCD 3.89; 3.154) |
| Obligations inside definitions; a defined term used in lowercase (*the approved budget*) | New inventory checks |
| *terminate by giving 30 days' notice* | New check (MSCD 13.623) |
| *$850,000.00* where no amount has cents | New check (MSCD 13.546) |
| *he or she*; a form labeled as a schedule; article headings not in capitals; typed numbers in a Word file | New checks (house rules 9, 6 and 3; MSCD 4.10) |
| *Twelve Oaks Mall* read as a spelled-out number | A capitalized number word before a capitalized word mid-sentence is read as a name |
| Markdown run-in headings (`A. **Heading.**`) read as missing, so "11 of 11 sections have no heading" | Fixed, with semicolons in headings too |
| Definitions run into a section, `The "Term" starts ...`, and `**"Cause"**` missing from the inventory, causing false severity-1 undefined-term flags | Fixed |
| Party names: purchase terms without *between*; 3-party introductory clauses with semicolons; *the Authority*, *the Loan*, *the Parts* read as parties | Fixed |
| Severities that disagreed with the records: *shall be governed by* cited the generic has-a-duty test (1) instead of MSCD 3.98 (3); *from ... to* and *by [date]* cited 15.16 and 13.608 instead of 10.23 (1); *shall mean* had no rule (now 6.42, 3) | Fixed; SKILL.md adds: when a finding is both a house-rule breach and an ambiguity, use the higher severity |
| Rule-trigger noise: statute sections read as dates (*8.2-725*, *4-9-509*), *material and workmanship*, *wholly owned*, *at least $2,000,000*, *the 5th day of each month*, *1.25 to 1.00*, *be open* as a passive | Suppressed |
| The skill told Comment mode to put `<w:br/>` inside comment text, which fails validation | Corrected (`</w:t><w:br/><w:t xml:space="preserve">`), and tested |
| `accept_changes.py` made clean copies that failed validation and kept every comment | New `scripts/redline.py` applies a list of edits as tracked changes and anchored comments, and builds the clean copy from the same list with no markup |
| Writing tracked changes by hand was the slowest step | `redline.py` (above) |
| Existing comments in a file weren't surfaced | The lint report lists them, and SKILL.md says to tell Blake whether any should come out before the file goes to the other side |
| Letter agreements got introductory-clause checks | Skipped for letter agreements; SKILL.md points to MSCD chapter 19 |
| A 40 KB lint report was too long to read | Rule-trigger lines are shorter; the c46 report is now 29 KB |

Declined, with the reason:

- *Landlord leases to Tenant* without *hereby*: MSCD 3.50 rates omitting *hereby* as acceptable, so it gets no lint check.
- A missing concluding clause: MSCD 5.5 lets you omit it.
