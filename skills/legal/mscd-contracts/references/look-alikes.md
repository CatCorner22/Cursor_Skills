# Look-alikes: correct text that resembles a problem

Each line is a sentence that is correct under MSCD and the house rules, though it resembles a problem the lint or a pattern-minded reader flags. Before you flag text that matches a pattern, search this file (`grep -i "<words>" references/look-alikes.md`). The note says why the text is correct. Built from the phrase-variant knowledge base (1,210 entries); the problem forms themselves are in `data/phrase-variants.json`, which the lint runs. The last section, "Recurring cases from blind tests", lists correct text that earlier reviews flagged by mistake.

## agrees-to

- *If a Shareholder transfers Shares to a Person that is not a Shareholder, that transfer will be valid only if the transferee agrees in writing to comply with this agreement.* Agrees describes a nonparty's future act inside a condition; it isn't language of obligation. (MSCD 3.361 (10-2))
- *In this agreement, "Agreed Value" means $2,500,000 for each Vessel.* A defined term that begins with Agreed. (MSCD 6.25)
- *Seller acknowledges that Buyer would not have entered into this agreement without the covenants in the section titled "Noncompetition."* Covenants is a noun here, not the verb. (MSCD 3.485)
- *If the parties agree on the Fair Market Value no later than 30 days after the Valuation Date, that value will be final.* An agreement is the event in a condition, not a substitute for shall. (MSCD 3.361)
- *Seller hereby sells the Assets to Buyer for the Purchase Price.* Language of performance with hereby is correct; don't confuse it with hereby agrees. (MSCD 3.59 (1-1))
