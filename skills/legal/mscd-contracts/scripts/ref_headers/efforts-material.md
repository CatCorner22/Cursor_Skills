# Efforts standards, material, and MAC

Use only *reasonable efforts*, with a performance standard (8.134-8.143); no hierarchy of efforts standards makes sense (8.3). Consider the core definition at 8.156. For *material*, decide which meaning the drafter intends, "nontrivial" or "dealbreaker" (9.21-9.32), then omit it, use *nontrivial*, or use a defined *Material* (9.51-9.64). Use 1 term, MAC (9.103-9.111), with the definition at 9.113-9.115.
